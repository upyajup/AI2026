PRODUCT OVERVIEW

프로젝트 핵심 개요

부산 축제 가이드 플랫폼이 해결하고자 하는 방향과 주요 대상을 소개합니다.

공공 데이터 연동

공공데이터포털(apis.data.go.kr) 부산광역시 축제정보 오픈 API(FestivalService/getFestivalKr)를 활용하여 최신 데이터 제공.

타깃 사용자

부산 지역 실거주 주민, 국내외 여행객 및 주말 나들이 객, 축제 및 행사 관심 고객 전체를 커버하는 범용 인터페이스.

서버 프록시 & 캐싱

Express 및 Vercel Serverless Function을 통해 API 키 노출을 방지하고, 15분 메모리 캐싱으로 빠른 속도와 폴백 보장.

관심 축제 저장

브라우저 localStorage를 연동한 로컬 북마크 시스템으로 별도 로그인 없이 내 축제 리스트 관리.

DEPLOYMENT GUIDE

Vercel 배포 및 환경변수 세팅

프로젝트 배포를 위한 5단계 가이드입니다.

환경 변수 설정 (.env)

Vercel 대시보드의 Environment Variables 메뉴에 등록할 서비스 키 명세입니다.

# 공공데이터포털 부산 축제 API 서비스키
BUSAN_FESTIVAL_SERVICE_KEY="YOUR_KEY"

# Gemini API Key (AI 추천 확장 시)
GEMINI_API_KEY="YOUR_GEMINI_KEY"

Vercel Deploy Step-by-Step

  1. 1 GitHub 레포지토리에 busan-festival-guide 프로젝트 푸시
  2. 2 Vercel 대시보드 로그인 후 Import Project 선택
  3. 3 Environment Variables 메뉴에 BUSAN_FESTIVAL_SERVICE_KEY 추가
  4. 4 vercel.json 설정을 통해 /api/* 경로가 Serverless Function으로 자동으로 라우팅됨
  5. 5 Deploy 실행 후 생성된 프로덕션 도메인에서 정상 동작 및 축제 데이터 수집 확인
